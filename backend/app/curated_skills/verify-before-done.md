# verify-before-done

## 언제 사용하는가
"완료했다 / 통과한다 / 고쳤다"고 말하기 전, 그리고 커밋 전.

## 목표
주장 대신 **증거**. 실제로 실행한 검증으로만 완료를 선언한다.

## 절차
1. 성공 기준을 검증 가능한 형태로 바꾼다. "고쳤다" → "이 명령이 exit 0".
2. 가능하면 통과를 증명할 체크(재현 케이스·테스트)를 **먼저** 만든다.
3. 구현한다.
4. 그 체크를 실행해 통과 출력을 눈으로 확인한다.
5. 관련 기존 테스트도 실행해 회귀가 없는지 본다.

## 검증
통과 출력을 실제로 봤는가. 안 봤으면 아직 완료가 아니다.

## 하지 말아야 할 것
- 실행 없이 "통과할 것"이라고 보고.
- 일부만 하고 완료로 보고(막힌 부분은 명시).
- 실패 로그를 숨기거나 건너뛴 단계를 완료처럼 말하기.
